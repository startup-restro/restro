# 🏢 Multi-Location & Franchise

> **Module**: Enterprise | **Total Features**: 15 | **All Phase 4**
> **Core Principle**: Central control with local flexibility.

---

## Features (All Phase 4)

**F-251: Multi-Branch Dashboard** — All locations on one screen: revenue, orders, alerts per branch
**F-252: Standardized Menu Push** — Push menu changes from HQ to all branches, one click
**F-253: Branch Comparison** — Side-by-side KPIs across branches
**F-254: Central Kitchen** — Manage central prep → production orders → branch transfer
**F-255: Franchise Controls** — Franchisor sets rules, franchisee operates within constraints
**F-256: Inter-Branch Transfer** — Move stock between locations with receiving confirmation
**F-257: Consolidated P&L** — Combined + per-branch drill-down
**F-258: Role Hierarchy** — Franchise owner > branch manager > staff
**F-259: Per-Branch Settings** — Different tax, hours, pricing, payments per location
**F-260: Branch User Management** — Staff scoped to their branch only
**F-261: Branch Checklist** — Configurable opening/closing checklist
**F-262: Performance Alerts** — Auto-alert HQ when branch metrics drop below threshold
**F-263: Shared Customer Profiles** — Same customer across chain locations, points accumulate
**F-264: Centralized Suppliers** — Manage suppliers at chain level, bulk pricing
**F-265: Branch Audit Trail** — HQ can view audit logs from any branch
